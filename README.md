# 寻龙诀 · 画境与回声

独立试玩版。俯视角探索十层古墓，找到每层镇墓冥器并破印后，拉动机械开关限时打开盗洞。第七层要破除两道封印，最终层要破除三道封印。

## 操作与声音

电脑使用 WASD / 方向键移动、Shift 疾行、Esc 暂停、M 静音。手机右下摇杆移动，另一根手指按住「疾行」。靠近石棺约 0.6 秒开棺，靠近祭坛约 1.2 秒触发。切屏自动暂停，回来后手动继续。

点击「点灯摸金」会在手势中启用环境音与音效。开始画面和暂停菜单提供「开启 / 试音」。如听不到试音，请检查媒体音量与蓝牙输出。音频使用本地原创 WAV 环境音与 Web Audio 合成音效，支持 playback 音频会话时主动启用；播放错误会显示提示。手机实际输出仍取决于浏览器、系统音量及音频路由。

## 墓室

| 墓室 | 玩法 |
| --- | --- |
| 落脚处 | 无敌人和机关出生，到达新层有两秒保护；初次罗盘放在附近 |
| 陪葬室 | 开棺可能发现冥器、空棺或起尸 |
| 供奉室 | 额外补给，部分石棺可开出糯米酒与玉衣 |
| 安息室 | 靠近祭坛恢复一点生命；满血时获得八秒护身；每座只生效一次 |
| 机关室 | 地面危险先预警再伤害；弩机瞄准线亮起后延迟发射 |
| 封印室 | 靠近祭坛解除出口封印，罗盘在取得冥器后优先指向未解封的祭坛 |
| 归墟水道 | 拉闸后盗洞显现 25 秒，并沿地面扩散本层灾害；超时需重新拉闸 |

罗盘跨层保留；每层仅一盏残油铜灯，照明 20 秒，最后 2 秒渐暗。照明、护身和驱尸效果不跨层。满血时地上的糯米酒会保留。疾行更容易惊动远处敌人。机关与吐毒尸无法隔墙直接瞄准；罗盘给出方位，不提供绕墙路径。小地图记录附近探索区域，并显示已发现的未开石棺和祭坛。

## 验证与开发

静态游戏资源位于 `out/`。`audio.js` 管理手势启音，`world.js` 定义楼层与墓室机制，`art.js` 加载图集并绘制，`game.js` 保留固定时间步主循环、输入与实体行为。无运行时包依赖。

运行 `node --test tests/game.test.cjs` 验证逻辑。测试使用 DOM / Media / Canvas 替身，不等于真机音频或浏览器触控验收。`scripts/render-check.cjs` 可用 `@napi-rs/canvas` 做离屏材质与场景渲染检查，不是浏览器截图。

`node scripts/render-check.cjs` 默认输出到忽略的 `tmp/render-check/`，需要环境能解析 `@napi-rs/canvas`（可通过 CODEX_PRIMARY_RUNTIME_NODE_MODULES 指定已安装模块位置）。`python scripts/create-audio.py` 可重建原创音频。

美术来源与图集映射见 `ASSETS.md`。游戏作者：Shuhan Sun。

动作更新：四方向步态由实际位移驱动；脚步与涉水音效已按反馈取消。僵尸有跳跃、落地、蓄力、攻击和恢复阶段；近战蓄力后可躲开，绿尸蓄力后吐毒。机关增加后坐力和发射特效，箭矢、滚石、滚木、火球、毒液使用独立贴图；地面为实体钉板和喷口。

甬道更新：地面钉板、喷口只出现在墓室外的通道，机关之间留出等候位置。发射器沿墙布置，平滑转向，发射前锁定方向，枪口和弹道共用朝向。手机左下疾行、右下摇杆；脚步与涉水音效已取消。盗洞显示下一层名称、描述、封印/积水提示和主题动画，确认后以 1.25 秒穿行进入下一层，过场冻结游戏时间；减少动态效果设置缩短至 0.2 秒。

逃生更新：机械开关驻足 1 秒开启；超时闭合并隐藏洞口，离开开关后可再次靠近拉闸。扩散按可通行格的距离推进，每秒 0.7 格，不穿墙；关闭后每秒消退 3 格。流沙/地下水/尸甲虫/岩浆/迷雾/尸水/毒气/藤蔓/硫酸/星陨瘴尘依次对应十层，减速、遮蔽、接触伤害分别配置。每层守墓者有独立名称、配色、大小、移速、感知范围、跳跃与蓄力节奏；火尸吐火、水尸不受原生积水减速。保留其他音效。


### 主墓室逃生与有限资源
盗洞位于主墓室内部，绞盘位于墓室外，至少相隔 500 像素，优先选择约 24 格通路距离。开闸后 25 秒内返回主墓室。水与沙减速，毒火等持续接触造成伤害，迷雾压缩包括油灯在内的视野。
只有持有罗盘才显示小地图。实际扣血时有 35% 概率掉落一件当前装备（罗盘、油灯或黑驴蹄子），两秒后可拾回，计时物品保留掉落前剩余时间。玉衣无时间限制，只抵挡一次伤害，不叠加；抵挡后短暂保护避免同帧连击。
每层固定生成 5+2×层数 件地面物品、4+2×层数 只初始僵尸，棺中僵尸另计。每层一盏油灯、一枚罗盘，其他供物有限且不会刷新。


隐藏测试入口：连续点击首页标题或游戏中的关卡名称五次，可跳转任意楼层；跳转重置本局装备和物资。手机在画面任意空白处按住拖动移动，松手停止，左下角独立疾行。纹理采用较大连续采样，扩散物以柔和不规则边缘覆盖地面。


选关入口初始化画布尺寸并等待美术资源就绪，修复从首页直接选关黑屏。墙体新增青砖侧面、落地阴影、碎石与缺口；通道提高明暗对比。墓室加入镇墓符、奠字刻砖、暗红血迹和残骨。
