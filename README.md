# 寻龙诀 · 画境与回声

独立试玩版。俯视角探索十层古墓，找到每层镇墓冥器后寻找盗洞。第七层要破除两道封印，最终层要破除三道封印。

## 操作与声音

电脑使用 WASD / 方向键移动、Shift 疾行、Esc 暂停、M 静音。手机右下摇杆移动，另一根手指按住「疾行」。靠近石棺约 0.6 秒开棺，靠近祭坛约 1.2 秒触发。切屏自动暂停，回来后手动继续。

点击「点灯摸金」会在手势中启用环境音与音效。开始画面和暂停菜单提供「开启 / 试音」。如听不到试音，请检查媒体音量与蓝牙输出。音频使用本地原创 WAV 环境音与 Web Audio 合成音效，支持 playback 音频会话时主动启用；播放错误会显示提示。手机实际输出仍取决于浏览器、系统音量及音频路由。

## 墓室

| 墓室 | 玩法 |
| --- | --- |
| 落脚处 | 无敌人和机关出生，到达新层有两秒保护；初次罗盘放在附近 |
| 陪葬室 | 开棺可能发现冥器、空棺或起尸 |
| 供奉室 | 额外补给，部分石棺可开出糯米酒与玉衣 |
| 安息室 | 靠近祭坛恢复一点生命；满血时获得八秒护身；每座只生效一次 |
| 机关室 | 地面危险先预警再伤害；弩机瞄准线亮起后延迟发射 |
| 封印室 | 靠近祭坛解除出口封印，罗盘在取得冥器后优先指向未解封的祭坛 |
| 归墟水道 | 取得冥器后涨水；收齐本层所需条件后进入下一层 |

## 十层变化

| 层 | 特征 |
| --- | --- |
| 1 沙海迷冢 | 砂岩地砖、较宽视野、基础守墓尸 |
| 2 千纹机关廊 | 狭长房间、弩箭和机关预警 |
| 3 青铜兽影厅 | 青铜材质、巡游卫尸与滚木 |
| 4 巨鼎炼魂室 | 黑石余烬、周期地火和喷火机关 |
| 5 石骨迷宫 | 更多小房间、短视野、疾行尸 |
| 6 荧光棺河 | 苔石积水、绿毒尸与毒液 |
| 7 九字封印井 | 紫黑祭石、两座封印祭坛 |
| 8 暗影葬主殿 | 黑曜石、最短基础视野、疾行尸与吐毒尸 |
| 9 帝王沉眠室 | 更大的金殿、供物与巨石机关 |
| 10 永劫天陨塔 | 天陨石、混合机关、积水与三道封印 |

油灯与罗盘跨层保留；临时护身和驱尸效果不跨层。满血时地上的糯米酒会保留。疾行更容易惊动远处敌人。机关与吐毒尸无法隔墙直接瞄准；罗盘给出方位，不提供绕墙路径。小地图记录附近探索区域，并显示已发现的未开石棺和祭坛。

## 验证与开发

静态游戏资源位于 `out/`。`audio.js` 管理手势启音，`world.js` 定义楼层与墓室机制，`art.js` 加载图集并绘制，`game.js` 保留固定时间步主循环、输入与实体行为。无运行时包依赖。

运行 `node --test tests/game.test.cjs` 验证逻辑。测试使用 DOM / Media / Canvas 替身，不等于真机音频或浏览器触控验收。`scripts/render-check.cjs` 可用 `@napi-rs/canvas` 做离屏材质与场景渲染检查，不是浏览器截图。

`node scripts/render-check.cjs` 默认输出到忽略的 `tmp/render-check/`，需要环境能解析 `@napi-rs/canvas`（可通过 CODEX_PRIMARY_RUNTIME_NODE_MODULES 指定已安装模块位置）。`python scripts/create-audio.py` 可重建原创音频。
