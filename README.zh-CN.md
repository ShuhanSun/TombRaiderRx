# 寻龙诀 · Tomb Raider

[English](README.md) | [简体中文](README.zh-CN.md)

一款以中国古墓、墓葬建筑、隐藏墓室、机关陷阱、陪葬冥器和尸祟传说为核心氛围的网页探墓游戏。

**当前试玩版：** https://tombraider-playtest.bookcool.chatgpt.site

你进入的是一座信息极少、危险未知的封闭古墓。玩家需要逐间探索墓室，观察环境，开启棺椁，寻找工具与冥器，在机关和尸祟之间活下来，打开主墓室，并在整座墓穴彻底失控前找到盗洞逃离。

## 核心探墓循环

1. **探索** —— 穿过墓道、耳室、陪葬室、隐藏房间和封闭墓室。
2. **调查** —— 观察棺椁、冥器、机关、血迹、墙体结构和环境线索。
3. **准备** —— 在进入高风险区域前寻找工具、照明和防护物品。
4. **生存** —— 躲避或处理尸祟，同时利用地形和墓穴机关降低风险。
5. **深入** —— 打开主墓室，处理守墓威胁，最终进入盗洞离开本层。

游戏目标并不是把古墓做成一个普通的打怪竞技场。战斗负责制造压力，真正推动体验的是探索、空间判断、风险管理和环境互动。

## 游戏特色

- **中国古墓氛围** —— 石质墓室、墓道、棺椁、陪葬品、暗处壁灯、隐藏空间和墓葬建筑结构。
- **真实感棺椁互动** —— 推开棺盖后，盖子仍然保留在场景中；棺内可能是空棺、补给、冥器，也可能直接蹦出尸祟。
- **环境危险** —— 喷火、喷水、毒烟、飞射物、滚石和其他墓穴机关拥有各自独立的视觉表现。
- **屏气机制** —— 玩家可以通过屏气暂时降低尸祟的攻击性，为重新走位创造机会。
- **探墓装备** —— 罗盘、油灯、木盾、兵工铲等装备直接影响探索方式和生存能力。
- **隐藏墓室** —— 一些陪葬空间藏在普通石墙之后，需要贴近环境仔细寻找。
- **电脑与手机兼容** —— 可直接在浏览器中使用键盘或触摸方式游玩。

## 装备

| 物品 | 作用 |
| --- | --- |
| 兵工铲 | 近距离攻击工具，可用于处理尸祟、爬行敌人和可破坏容器。 |
| 罗盘 | 解锁小地图、目标方向等导航能力。 |
| 油灯 | 在一段时间内提高暗处可见度。 |
| 金缕玉衣 | 抵挡一次伤害。 |
| 木盾 | 在耐久耗尽前抵挡有限次数的攻击。 |

装备数量保持有限。游戏希望玩家依靠路线、时机、站位和风险判断生存，而不是靠数值碾压所有敌人。

## 操作

### 电脑

- **WASD / 方向键** —— 移动
- **Shift** —— 疾行
- **B** —— 屏气
- **Esc** —— 暂停
- **M** —— 静音

攻击和附近交互采用情境触发逻辑。取得兵工铲后，在条件满足时可自动攻击附近的有效目标。

### 手机

在游戏画面上拖动控制移动。疾行、屏气和情境操作通过屏幕按钮完成。交互区域针对移动浏览器做了处理，避免快速操作时触发网页双击放大。

## 关卡设计

当前游戏包含十层墓穴。随着深入，墓穴空间逐渐扩大，墓室组合、棺材、机关、尸祟和隐藏区域的关系也会变得更复杂。

地图保存在 `levels.js` 中，布局可以稳定复现，便于平衡、测试和 Bug 重现。后期难度主要来自空间关系和多种危险组合，而不是单纯提高敌人血量。

## 视觉与交互目标

项目整体追求偏写实的 2.5D 古墓探索感，而不是明亮的街机风格。墙体需要像真正的建筑结构一样具有高度、阴影和体积感；烟雾必须保持半透明，危险不能以完全遮挡玩家视野为代价。

重要物体尽量通过造型、光照、动画和摆放方式自然引导玩家，而不是依赖大量文字箭头。

人物动画区分行走、攻击、推棺、屏气、受伤和持盾状态。棺材打开后，棺盖会保留在场景中，而不是像普通宝箱一样直接消失。

## 本地运行

无需构建。

```bash
python3 -m http.server 8000
```

浏览器打开：

```text
http://localhost:8000
```

发布或本地运行时，请保留根目录 HTML、CSS、JavaScript 文件以及完整的 `assets/` 目录。

## 测试

需要 Node.js 22 或以上。

```bash
node --test tests/*.test.cjs
```

自动化测试覆盖核心玩法，包括地图扩展、动作图集、棺材、冥器、物品详情、木盾耐久、陷阱、隐藏墓室、敌人行为、返棺逻辑、推棺、自动攻击、屏气和输入控制等。

浏览器接口替身不能完全代替真机测试，因此手机触控、音频、渲染和移动端性能仍需要人工验收。

可选渲染检查：

```bash
node scripts/render-check.cjs
```

安装 `@napi-rs/canvas` 后，截图会输出到 `tmp/render-check`。
